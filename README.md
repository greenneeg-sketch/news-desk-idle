# NEWS DESK 8BIT

뉴스 편집실 방치형 게임 (16비트 스타일). 정적 호스팅(GitHub Pages)으로 동작합니다.

## 구조
```
index.html            배포용 한 파일 (build.py가 생성, 직접 고치지 않음)
dev.html              개발용 진입점 (ES 모듈)
build.py              dev.html + js + css → index.html
css/main.css          8비트 테마
js/main.js            Composition Root (조립만)
js/core/              EventBus(Observer), Store(Redux식 단일 상태), Loop(고정 타임스텝)
js/data/config.js     업그레이드, 이벤트, 단계 등 데이터 (밸런스 조정은 여기서)
js/state/reducer.js   상태 전이 (순수 함수)
js/systems/           economy(순수 계산), events(속보 스케줄러)
js/services/          storage(Repository), audio(8비트 효과음)
js/ui/                scene(픽셀 렌더러), hud(DOM 뷰)
```

## 배포
1. `dev.html`, `js/`, `css/`를 고친다.
2. `python3 build.py`로 `index.html`(모든 코드가 들어간 한 파일)을 만든다. 타이틀 화면 왼쪽 위에 빌드 번호가 찍힌다.
3. 저장소에 올리면 GitHub Pages(Settings > Pages, `main` / root)가 `index.html`을 연다.

한 파일로 배포하는 이유: GitHub Pages는 파일을 최대 10분 캐시하는데, 파일이 여러 개면 브라우저가 새 파일과 옛 파일을 섞어 써서 게임이 멈출 수 있다.
개발용 `dev.html`은 ES 모듈이라 로컬에서는 `python3 -m http.server`로 열어야 한다.

## 순위 보드 (사용자 간 순위)
- 순위 점수 = 30*log10(1+누적 점수) + 0.6*최대 레벨 + 4*최고 시청률 + 10*log10(1+유튜브 조회수) (`js/systems/ranking.js`)
- 서버를 연결하지 않으면 샘플 방송국과 비교하는 오프라인 모드입니다. 플레이어끼리 순위를 보려면 Supabase(무료)를 연결합니다.

### Supabase 연결
- 현재 연결: 프로젝트 `dailykit-game`(ndyiuefcvhnqnfdziacv)에 `nd_leaderboard`·`nd_lb_keys` 테이블과 `nd_submit`·`nd_server_time` 함수로 적용됨. 다른 게임 테이블과 겹치지 않게 이름에 `nd_`를 붙였습니다.
- 로그인 없이 동작합니다. Supabase 인증 설정을 바꾸지 않으므로 회원 로그인을 쓰는 다른 게임에 영향이 없습니다.
- 새 프로젝트에 다시 설치하려면 **SQL Editor**에 `supabase/setup.sql`을 붙여넣고 Run, 그다음 Project URL과 anon(공개) 키를 `js/data/config.js`의 `LEADERBOARD`에 넣고 `python3 build.py`. **service_role 키는 절대 넣지 마세요.**

### 서버 쪽 보호 (`supabase/setup.sql`)
- 기기 열쇠: 기기마다 무작위 id와 비밀 열쇠를 만들어 기기에만 보관하고(localStorage `newsDeskSb`), 서버에는 열쇠의 해시만 저장합니다. 열쇠가 맞아야만 그 방송국 기록을 고칠 수 있습니다.
- 테이블에 직접 쓰기는 막혀 있고, 쓰기는 `nd_submit()` 함수로만 됩니다. 순위 점수는 서버가 계산합니다.
- 이름 규칙(2~12자)과 비속어·운영자 사칭을 서버에서도 막습니다.
- 순위 점수가 너무 빨리 오르면(1분당 +30, 기본 +60 초과) 거부, 첫 등록은 600점까지, 15초에 한 번만 반영합니다.
- 출석·주간·시즌 날짜는 서버 시각(`nd_server_time()`)으로 계산해 기기 시계 조작을 막습니다.
- 부적절한 이름은 Supabase **Table Editor → nd_leaderboard**에서 운영자가 직접 고치거나 지울 수 있습니다.
- 한계: 게임 진행 자체는 기기에서 계산되므로 완벽한 부정행위 방지는 아닙니다. 브라우저 데이터를 지우면 열쇠도 사라져 새 방송국으로 등록됩니다.

### 푸시 알림
- 성장 탭 설정의 **알림 켜기**. 앱을 닫으면 '야간 근무 수익이 가득 차는 시각'(8시간 + 야간 근무조 연구)에 알림을 예약하고, 다시 열면 취소합니다.
- 아이폰은 iOS 16.4 이상에서 **홈 화면에 추가한 앱**으로 열었을 때만 알림을 받을 수 있습니다.
- 서버: `nd_push` 테이블, `nd_push_set`(기기 열쇠 확인), pg_cron이 10분마다 `nd_push_tick()` → 서버 함수 `nd-push`(`supabase/functions/nd-push/index.ts`)가 발송. 서명 열쇠(VAPID)는 함수가 처음 실행될 때 만들어 Supabase Vault에 보관합니다.

### 클라우드 저장
- 순위 서버에 방송국이 등록되면 2분마다, 그리고 앱을 닫을 때 저장본을 서버(`nd_saves`)에 올립니다. 성장 탭에 **복구 코드**(12자리)가 나옵니다.
- 다른 기기에서 복구 코드를 넣으면 저장본을 불러오고, 그 방송국의 기기 열쇠가 새 기기로 옮겨집니다(옛 기기는 더 이상 저장하지 못함).
- 복구 코드는 기록의 열쇠이므로 다른 사람에게 알려 주면 안 됩니다. 틀린 코드는 1초씩 늦게 응답해 무작위 대입을 어렵게 합니다.

## UI/UX 원칙 (단계적 공개)
- 처음엔 보도국의 핵심(5개 층·구매 수량·8시 뉴스 한 줄)만 보이고, 누적 점수에 따라 기능이 하나씩 해금된다(`js/data/tips.js`의 `UNLOCKS`): 속도 부스트 300 → 매니저 1천 → 미션 2천 → HQ 3천 → 스카우트 탭 5천 → 성장 탭 1만 → 순위 탭·팀장 2만 → 꾸미기 3만 → 데스크 판단 5만 → 연구소·주간 이벤트 10만 → 개편 50만.
- 잠긴 탭은 자물쇠로 표시되고 누르면 해금 조건을 알려 준다. 예전 저장본은 이미 넘은 기능이 조용히 모두 열린다.
- 창은 한 번에 하나만(튜토리얼이 끝난 뒤, 2.5초 간격) 대기열로 띄운다: 승진 창, 해금·상황 안내 카드. 신문은 '신문 도착' 버튼을 눌러 원할 때 본다.
- '추천' 버튼: 병목 층 업그레이드 → 병목 층 매니저 → 살 수 있는 가장 싼 업그레이드 순서로 하나만 반짝인다.
- 8시 뉴스는 한 줄로 접혀 있고 누르면 자세히(라이벌·기록·조회수)를 연다. 데스크 판단 카드는 보도국 탭에서만, 다른 창이 없을 때 뜬다.
- 성장 탭은 하위 탭(커리어·연구·꾸미기·개편·업적), 클라우드 저장·소리·알림·이름·타이틀·초기화는 오른쪽 위 ⚙ 설정 창.
- 첫날 출석 보너스는 300점(시작하자마자 큰 보상으로 해금·승진이 한꺼번에 터지지 않게).

## 새 기능 안내 팁
- `js/data/tips.js`: 미션·데스크 판단·주간 이벤트·라이벌·연구소·꾸미기·개편·로봇·클라우드 저장을 처음 만날 때 한 번씩 안내합니다. 본 팁은 저장(`tips`)되어 다시 나오지 않습니다.

## 배경음악
- `js/services/music.js`: Web Audio로 연주하는 오리지널 8비트 곡 3개(타이틀·보도국·속보). 음원 파일이 없어 저작권 문제가 없습니다. 곡은 같은 파일의 `SONGS` 표기(16분음표 한 칸 = 토큰 하나)로 고칠 수 있습니다.

## 직업 / 커리어 / 뉴스 디펜더즈 / 주간 한정 이벤트
- 직업(`JOBS`): 처음에 방송국 이름과 함께 고른다(취재기자·영상기자·영상편집기자·그래픽 디자이너·방송 엔지니어). 주력 층 속도 +50%, 그 층 업그레이드 비용 -20%, 직업별 특기. '이름·직업' 버튼으로 바꿀 수 있고 직급 단계는 유지된다. 직업을 고르기 전 저장본은 영상편집기자로 본다.
- 커리어(`JOBS[].career`): 직업마다 직급 이름·승진 조건·대사가 다르다(예: 방송 엔지니어는 수습 엔지니어 → 방송 엔지니어 → 선임 엔지니어 → 주조정실 기술감독 → 방송기술부장 → 기술본부장). 승진마다 영구 점수 +5%와 티켓.
- 스카우트 카드 그림(`js/ui/cardart.js`): 카드마다 머리·피부·옷·소품이 다르고, ★2는 은빛 액자·옷깃·소품 업그레이드, ★3은 금빛 액자·금장식·빛줄기·반짝임.
- 히어로 카드 4장(전설 등급, `CARDS`의 `hero`). 거대 로봇 속보(`EVENTS`의 `robot`, 누적 100만 점부터) 때 1장당 점수 +50%.
- 주간 한정 이벤트(`WEEK_EVENTS`): 매주 월요일 교체(대선 개표·스포츠 대회·태풍·로봇 출몰·특종 사냥·시청률 전쟁). 목표 달성 시 티켓 2장 + 한정 배지.

## 홈 화면 앱 (PWA)
- `manifest.webmanifest`, `icons/`, `sw.js`. 안드로이드 크롬은 타이틀 메뉴의 **앱 설치**, 아이폰 사파리는 **공유 → 홈 화면에 추가**.
- 서비스 워커는 같은 사이트 파일을 '네트워크 우선'으로 받아 항상 최신 버전을 확인하고, 인터넷이 없을 때만 저장본으로 실행합니다. `build.py`가 빌드마다 캐시 이름을 바꿔 옛 캐시를 지웁니다.

## 방송국 이름
- 한글·영문·숫자 2~12자, 비속어와 운영자 사칭 단어는 `js/systems/nameFilter.js`에서 차단하고, 순위 보드에 표시할 때도 다시 거릅니다. 이름 변경은 하단 버튼에서 합니다. 서버를 연결하면 서버에서도 같은 검사를 해야 합니다.
- 게임 속 하루 길이는 `js/data/config.js`의 `DAY_SEC`(현재 300초 = 5분)입니다.

## 직원 카드 도감 / 주간 목표 / 출석
- 스카우트 확률은 꽝 45%, 일반 30%, 희귀 17%, 영웅 6.5%, 전설 1.5%이고 30번째는 영웅 이상 보장입니다(꽝이면 점수로 뽑은 경우 비용의 20%를 돌려줍니다)(`js/systems/cards.js`). 카드와 주간 목표는 `js/data/config.js`의 `CARDS`, `WEEKLY`에서 고칩니다.
- 스카우트 가격은 뽑을 때마다 15%씩 오르고(상한 없음), 최소한 평소 수입 10분치입니다(`js/systems/cards.js`의 `scoutCost`).
- 출석과 주간 초기화는 기기 시계(로컬 날짜) 기준입니다. 서버를 붙이면 서버 시간을 써야 시계 조작을 막을 수 있습니다.

## 시즌 / 챌린지
- 시즌은 매월 1일 시작(기기 날짜 기준). 시즌 점수 = 시즌 시작 이후 번 점수, 등급 브론즈~다이아(`TIERS`). 시즌이 끝나면 등급에 따라 티켓 1~5장. 시즌 테마(`SEASON_THEMES`)는 해당 속보를 3배 자주 발생시킵니다.
- 순위 보드에서 "전체 / 이번 시즌"을 전환합니다. Supabase를 쓰면 테이블에 `season text, season_pts double precision` 열을 추가하세요.
- 챌린지(`CHALLENGES`)를 시작하면 회차가 초기화되고, 목표를 달성하면 영구 점수 +10%. 개편하면 진행 중 챌린지는 포기됩니다.

## 화면 구성 / 튜토리얼
- 하단 탭: 보도국(층·HQ) / 스카우트(도감·주간 목표) / 순위(시즌·순위 보드) / 성장(개편·챌린지·업적·설정). 속보 경보·특종·알림은 어느 탭에서나 보입니다.
- 첫 방송을 시작하면 7단계 가이드가 나옵니다(`js/ui/tutorial.js`). 일부 단계는 직접 해 보면 자동으로 넘어가고, 위의 ? 버튼으로 다시 볼 수 있습니다.

## 인트로 타이틀
- `js/ui/intro.js`: 방송국 건물 픽셀 아트 타임랩스(하루 20초, 계절마다 2일), 중계 헬기, UFO vs 전투기, 오리지널 히어로 '뉴스 디펜더즈'(캡틴 큐시트·프레임 닌자·메카 앵커·나이트 에디터), 거대 로봇 습격, 건물 파괴와 복구, 하단 뉴스 자막.
- 테스트용: 주소 뒤에 `?it=130`처럼 붙이면 그 시점(초)부터 시작합니다(130 ≈ 겨울).

- 설정의 "타이틀" 버튼으로 다시 볼 수 있습니다.
